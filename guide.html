Getting Started

Install the No3D Tools extension and sync your managed asset library into Blender.

What You Get

Your No3d Tools subscription gives you a synced asset library inside Blender's Asset Browser. Geometry node tools, materials, mesh objects — all drag-and-drop ready. New assets are synced automatically when you open Blender.

Requirements

  • Blender 5.0 or newer
  • An active subscription — subscribe here
  • Your No3D Tools License Key (emailed after subscribing)

Install the Extension

Step 1: Open on Your Blender Computer

If you purchased on your phone, reopen this page from your email or account on the computer where Blender is installed.

OPEN IN BLENDER

This adds the official No3D Tools repository to Blender and opens Get Extensions. Future extension updates are delivered through Blender.

Step 2: Install in Blender

1. Open Blender

2. Go to Edit → Preferences → Get Extensions

3. Find No3D Tools in the official No3D Tools repository

4. Click Install

Step 3: Open Preferences

1. Go to Edit → Preferences → Add-ons

2. Search for No3D Tools

3. Expand the extension preferences

Manual installation fallback

If native repository installation is unavailable, download the current extension ZIP, then use Edit → Preferences → Extensions → menu → Install from Disk. Native repository installation is recommended because Blender can deliver extension updates automatically.

Setup and Sync

The extension preferences panel walks you through setup with numbered steps. Open it at Edit → Preferences → Add-ons → No3D Tools.

Step 1. Enter your No3D Tools License Key

Paste your key into the Key field. Format: NO3D-XXXX-XXXX-XXXX-XXXX

Step 2. Activate and set startup sync

Click Activate No3D Tools. Check Sync on startup to automatically sync when Blender opens.

Individually purchased tools

Click Connect Purchases, approve the connection in your browser, then click Restore Purchases. Purchased products become part of your managed Blender Asset Library.

Step 3. Choose install location

The default location is ~/Documents/No3d Tools. Change it if you want assets stored elsewhere.

Step 4. Activate No3D Tools

Click Activate No3D Tools to confirm the install folder and run your first sync. Assets are always stored in a "No3d Tools" subfolder. If the library appears empty, click Refresh No3D Tools Library or try refreshing the Asset Browser panel.

Don't have your key? Open My Library or check your purchase email.

Troubleshooting

"Invalid No3D Tools License Key"

  • Include the NO3D- prefix
  • Check for extra spaces
  • Verify your access in My Library

"Sync failed"

  • Check your internet connection
  • Click Activate No3D Tools first, then try again
  • If it persists, try Recover Setup under Maintenance Tools

Assets not showing in Asset Browser

  • Select NO3D Tools in the Asset Browser dropdown (top left)
  • Click Refresh No3D Tools Library in addon preferences
  • If still empty, try refreshing the Asset Browser panel

Lost your No3D Tools key

  • Check email for "No3d Tools — Your No3D Tools License Key"
  • Visit My Library and enter your email
